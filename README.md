# Naive Bayes Implementation with Scikit-Learn

A beginner-friendly machine learning project that implements the Gaussian Naive Bayes algorithm using Scikit-Learn.

## 📌 Project Overview

This project uses the Breast Cancer dataset to build and evaluate a Gaussian Naive Bayes classification model.

The workflow includes:

- Loading the Breast Cancer dataset
- Converting the data into a Pandas DataFrame
- Exploring target classes and class distribution
- Splitting the dataset into training and testing sets
- Training a Gaussian Naive Bayes model
- Making predictions
- Evaluating model accuracy
- Generating a Confusion Matrix
- Displaying a Classification Report
- Interpreting TN, FP, FN, and TP values
- Predicting a new sample

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Scikit-Learn
- Jupyter Notebook

## 📊 Dataset

The project uses the Breast Cancer dataset available in Scikit-Learn.

Dataset size: 569 samples

Target classes:
- Malignant
- Benign

## 🤖 Machine Learning Model

Gaussian Naive Bayes (`GaussianNB`) is used for classification.

## 📈 Model Evaluation

The model is evaluated using:

- Accuracy Score
- Confusion Matrix
- Classification Report
- Precision
- Recall
- F1-Score

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/abdullahshaheer901-pixel/Naive-Bayes-Implementation-with-Scikit-Learn.git
```

Move into the project folder:

```bash
cd Naive-Bayes-Implementation-with-Scikit-Learn
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run Jupyter Notebook:

```bash
jupyter notebook
```

Then open:

```text
Naive Bayes Implementation Project.ipynb
```
